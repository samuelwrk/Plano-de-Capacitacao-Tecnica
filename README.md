# 🚀 Capacitação Técnica: Transição PHP para React

Este repositório contém o progresso e as entregas do meu **Plano de Especialização em React**. O programa foca na modernização de arquiteturas legadas em PHP para interfaces escaláveis e componentes modernos.

---

## 🎯 Objetivo Estratégico
Promover a proficiência técnica em React, habilitando o desenvolvimento de soluções escaláveis e a integração em projetos de alta complexidade.

---

## 📅 Cronograma de Evolução
O treinamento é estruturado em oito semanas de maturação técnica:

### 🔹 Fase 1: Fundamentos e Base Web
* **Semana 1 - Base Web & Git:** Nivelamento em HTML5, CSS3 e fluxo de trabalho com Git.
* **Semana 2 - JavaScript Moderno:** Domínio de ECMAScript 6+ (*Promises, Async/Await e Módulos*).

### 🔹 Fase 2: Imersão em React
* **Semana 3 - Fundamentos:** JSX, Componentes, Props, State e Ciclo de Vida.
* **Semana 4 - React na Prática:** Hooks (`useState`, `useEffect`), renderização condicional e React Router.

### 🔹 Fase 3: Integração e Arquitetura
* **Semana 5 - Integração PHP:** Consumo de APIs backend em PHP e tratamento de estados assíncronos.
* **Semana 6 - Organização e Padrões:** Implementação de *Atomic Design* e estruturação de projetos escaláveis.

### 🔹 Fase 4: Produção e Autonomia
* **Semana 7 - Projeto Guiado:** Atuação supervisionada em módulos de produção reais.
* **Semana 8 - Autonomia:** Resolução independente de bugs e melhorias técnicas.

---

## 🛠️ Metodologia e Entrega
As entregas são validadas semanalmente via **Pull Request**, simulando o fluxo real da equipe de engenharia com revisões de código (*Code Review*).
